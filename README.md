# In-Memory-Database
An interactive command-line interface that stores and manipulates key-value data directly in memory.

## Requirements: 
- Python3
- libraries: json (no external libraries)

## How to run?
'python inmemory_database.py'

## Commands:
- SET (SET <key> <value>): Stores a value under a key.
  
- GET (GET <key>): Returns the value stored under the key entered by the user.
  
- DEL (DEL <key>): Deletes the key from the database.
  
- EXISTS (EXISTS <key>): Returns 0 or 1 depending on whether the key entered by the user exists in the database or not.
  
- SAVE (SAVE <filename>): Saves the database in a file.

- LOAD (LOAD <filename>): Loads a database from a file in the directory.

- EXIT (EXIT): To exit the command-line interface.
